# Снятие кузова и замена батареи с новым приводом, 0.1

15 сентября 2026. [Интерактивное снятие кузова](viewer.html) · [геометрический отчёт](../../docs/evidence/current-service-v01.json).

Проверена текущая начальная компоновка: электроника 0 мм, камера +3 мм. Учтены новый носитель TA6586 с компонентами и нижним C1, его поддон/прижим/крепёж, новый антенный кабель и три отдельных провода FI/BI/GND. Всего 152 неподвижных тела, включая 103 размерных объёма компонентов XIAO. Прежние прямоугольник драйвера и одиночная линия управления исключены. Проверка заново читает геометрию; результаты старых компоновок не перенесены автоматически.

| Операция | Условия и движение | Результат геометрической проверки |
| --- | --- | --- |
| Снять условный кузов | Питание выключено, внешние USB-кабели отключены. Крышка зарядного порта движется вместе с кузовом; батарея, крепления и жгут остаются на машинке. Поднять на 2 мм, сдвинуть вправо (+X) на 1 мм, затем поднять до смещения +65 мм | 265 положений с шагом 0,25 мм, пересечений объёмом более 0,001 мм³ не найдено |
| Снять левый упор батареи | Кузов и удерживающая лента сняты. Сдвинуть левый упор наружу по −X до 6 мм; правый остаётся | 25 положений с шагом 0,25 мм, пересечений не найдено |
| Вынуть макет батареи | Кузов, лента и левый упор сняты; питание выключено, аккумулятор отключён. Выдвинуть коробку аккумулятора на 50 мм влево | Непрерывный объём прямолинейного перемещения коробки не пересекает проверенные детали и правый упор |

Это маршрут для проектируемой геометрии, а не инструкция силой двигать реальный кузов по заданным миллиметрам. Проверка подтверждает отсутствие найденных коллизий; минимальный технологический зазор и удобство руками не определены. **Реальные разъём и хвост аккумулятора не смоделированы:** отключение/освобождение проводов обязательно, возможность физической быстрой замены ещё не доказана.

Контрольные неправильные операции дают ожидаемые пересечения: оставленный левый упор блокирует батарею (123,000 мм³), прямой подъём кузова без бокового смещения задевает USB-разъём (14,821 мм³). Проверка не игнорирует этот разъём. Три провода управления при снятии кузова остаются на своих местах; это не подтверждение возможности снять саму плату или камеру с подключённым жгутом.

В просмотрщике ползунок показывает только проверенные положения кузова. Кнопки «Установлен» и «Поднят» переключают крайние положения; электроника остаётся неподвижной. Движущиеся контуры построены из рёбер тех же STL, которые проверяет скрипт. Служебные размерные резервы и серая исходная механика в сцене не означают, что все эти детали включены в расчёт: точный список приведён в `fixed_inventory` отчёта. Батарейная операция пока описана в таблице, отдельной анимации нет.

Ограничения: условный кузов вместо выбранной модели; шаговая проверка кузова/упора, без непрерывного доказательства между отсчётами; нет пальцев, магнитов, стяжек, сил, изгибов кабелей и части исходной подвески/передачи. Зарядная плата остаётся размерным резервом, проводка питания/мотора/серво — предварительными трассами. Другие положения продольных регулировок требуют отдельной проверки. Физическая печать отложена пользователем; испытания механики и электрической части не выполнены.

Воспроизведение:

```powershell
uv run --with-requirements tools/cad-candidate-requirements.txt python tools/check_current_service.py
uv run --with-requirements tools/cad-candidate-requirements.txt python tools/build_service_viewer.py
```

Отчёт содержит SHA256 55 источников; отдельный [манифест просмотрщика](../../docs/evidence/current-service-viewer-v01.json) связывает HTML с исходной сценой и результатом расчёта. [Проверка в браузере](../../docs/evidence/current-service-browser-v01.json) подтверждает крайние положения, два промежуточных этапа, кнопки и отсутствие ошибок WebGL в проверенных кадрах. Это не физическая проверка.
