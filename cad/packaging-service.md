# Обслуживание компоновки 0.5 — проверка 0.1

15 сентября 2026. Проверено по текущей цифровой компоновке до получения посылок.
Это предложение для SWAP-01/MOUNT-01, не подтверждение физической сборки.

## Результат

| Операция | Проверка | Результат для учтённых тел |
| --- | --- | --- |
| Снять кузов вместе с крышкой зарядного порта | Поднять на 2 мм, сдвинуть на 1 мм к стороне USB (+X), затем поднять до +65 мм; 76 положений | Пересечений не найдено |
| Снять левый упор батареи после освобождения ремешка | Смещение наружу на 6 мм, 25 положений через 0,25 мм | Пересечений не найдено |
| Выдвинуть батарею влево | Полный непрерывный объём хода макета на 50 мм по −X; кузов, ремешок и левый упор сняты | Пересечений не найдено; правый упор можно оставить |
| Попытаться выдвинуть батарею с левым упором | Положительный контроль обнаружения коллизий | Пересечение 123,000 мм³ |
| Поднять кузов прямо вверх на 7 мм | Положительный контроль зацепления USB | Пересечение с гнездом 14,821 мм³ |

Практическое уточнение: для предложенной смены аккумулятора достаточно освободить
ремешок и убрать **левый** упор. Правый, со стороны зарядного USB, может оставаться.
Упор не является самостоятельной защёлкой: его удержание ремешком ещё нужно проверить.
Снятие кузова остаётся составным движением; простые вертикальные направляющие
будущего магнитного крепления могут ему помешать.

Предлагаемый порядок: выключить машину и отключить внешний USB; снять кузов,
отключить аккумулятор за разъём, освободить ремешок и левый упор, вывести провод
аккумулятора из пути и выдвинуть пакет влево. Обратную сборку и повторное управление
выполнять с нейтральной командой. Проверка геометрии не подтверждает электрическую
блокировку тяги, распиновку или безопасный заряд.

## Границы проверки

Положение плат/камеры только **0/+3 мм**. Учтены новая рама, корпус SG90, мотор,
ограничивающий объём XIAO, поддон, опоры, резервы двух будущих плат, Waveshare
с резервом ответного разъёма, антенна с опорой, пять трасс проводов, основные
модели крепежа, батарейные элементы и пассивный USB-порт. Полный список исходных
файлов и SHA256 находится в отчёте.

Не учтены реальные пальцы, магниты, гибкость ремешка, разъёмы и хвост провода
самого аккумулятора, все детали исходной подвески/передачи, фактический кузов,
полностью населённые PCB и штекер сервисного USB XIAO. Крепление камеры и плат
по-прежнему требует проработки. Свободный путь коробки батареи не означает,
что реальную батарею с проводами уже можно сменить без зацепления.

Ход батарейного макета проверен целиком: при прямом перемещении прямоугольного
тела используется точный вытянутый объём. Путь упора и кузова проверен только
в отдельных положениях; между ними зазор не доказан. Проверка остальных пяти
допустимых сочетаний регулировок остаётся отдельной задачей.

Обнаружено техническое ограничение: сохранённый `wire-power.stl` из 0.5 не является
замкнутым телом после экспорта в STL. Он остаётся визуализацией. Для всех пяти
трасс проверочные тела заново построены из зафиксированных точек и радиусов
отчёта 0.5 и проверены на замкнутость; исходные отображаемые STL не исправлялись.

## Что можно делать дальше без деталей

1. Разработать удержание XIAO и фиксаторы плат, учитывая их контакты и доступ к USB.
2. Спроектировать крепление кузова, допускающее найденный путь снятия, и места
   фиксации жгута; затем пересчитать обслуживание с этими добавлениями.
3. Расширить полезное перемещение площадок и проверить обслуживание во всех
   разрешённых положениях. Длина пазов сама по себе этого не обеспечивает.
4. Скомпоновать плату драйвера и согласовать полный узел питания/заряда, чтобы
   заменить прямоугольные резервы реальными платами.
5. Подготовить небольшие образцы посадок для печати на K1C и сценарии испытаний
   управления/камеры, которые будут запущены после получения деталей.

Посылки нужны для размеров конкретных исполнений, реальной посадки, удержания,
RF/FPV, токов, нагрева и испытаний движения. Они не препятствуют перечисленным
проектным работам. Приоритет следующей CAD-итерации — удержание XIAO и жгута;
покупной кузов пока не выбран.

Воспроизведение из корня репозитория:

```powershell
uv run --with-requirements tools/cad-candidate-requirements.txt python tools/check_packaging_service.py
```
