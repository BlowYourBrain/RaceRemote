# Резерв жгута сервопривода

Следующий этап: [провод от площадки D3](../servo-wiring/README.md). Эта страница сохраняет исследование общего резерва.

15 сентября 2026. SERVO-BUNDLE-01 v0.1 — геометрическое предложение. [Интерактивная сборка](viewer.html), [расчёт](../../docs/evidence/servo-bundle-v01.json). Продолжает [компоновку с H10](../xiao-return-h10/README.md).

Старый коридор серво Ø1,8 мм пересекал C2 на 2,472 мм³. Теперь место для трёх проводов зарезервировано вдоль правого края электроники, с обходом C2 и крышки направляющих. Синий объём — новый маршрут; выключенный по умолчанию красный — прежний. STL в этой папке обозначают занятое пространство, **это не детали для печати**.

Предположение: три отдельных провода Ø1,4 мм с расстоянием между центрами 1,6 мм в треугольном сечении помещаются в круг Ø3,3 мм. Это не измерение заводского кабеля заказанного SG90. Размер разъёма, выход кабеля, радиусы изгиба, крепление, ток и распиновка остаются неизвестными.

Точки оси в координатах машины, мм:

```text
(42,78,38) → (48.4,78,38) → (48.4,92,34)
→ (48.4,95,19) → (44,89,16) → (43,78,14)
```

Длина оси 55,505 мм — не длина отрезаемого провода. Оба конца являются точками компоновки, а не назначенными электрическими контактами. Подключение питания серво и D3/GPIO4 ещё не разведено.

| Проверка | Результат |
| --- | --- |
| Старый коридор Ø1,8 мм | Пересечение C2: 2,472 мм³ |
| Старый маршрут при Ø3,3 мм | C2: 11,497; крышка: 6,438; FI: 0,428; BI: 0,266 мм³ |
| Новый резерв Ø3,3 мм | Пересечений с проверенными препятствиями нет |
| Выход нового резерва за условную полость кузова | 0 мм³ |
| Обслуживание при электронике 0 / камере +3 мм | 168 неподвижных объектов; 265 положений кузова и 25 положений упора проходят |
| Извлечение коробки аккумулятора | Непрерывный выход на 50 мм влево проходит при снятых кузове, ленте и левом упоре |

Для извлечения предполагаются выключенное питание, отсоединённые USB и аккумулятор. Проверка относится к условному кузову и номинальному положению электроники; движение рулевого механизма/подвески, пальцы, реальный кабель и его деформация не проверены. Сохраняются прежние конфликты резерва клеммы мотора A и старого силового коридора. Полная сборка и жгут не квалифицированы. Печать отложена пользователем.

Воспроизведение после подготовки исходной сборки H10:

```powershell
uv run --with-requirements tools/cad-candidate-requirements.txt python tools/build_servo_bundle_study.py
uv run --with-requirements tools/cad-candidate-requirements.txt python tools/build_servo_bundle_view.py
```

Отчёты содержат SHA256 входов и результатов. Браузер сообщил 75 уникальных объектов, отрисованный canvas и WebGL error 0; регулировки скрыты, поскольку другие положения не проверялись. Получение скриншота завершилось тайм-аутом; визуальная проверка по скриншоту не заявляется.
