Пара питания серво теперь проходит через **существующее седло верхнего прижима XIAO**. Через готовое отверстие в крыле прижима проходит петля шнура. Печатные детали, винты, платы и сигнальный провод D3 не изменены. Переложены только два провода возле прижима; их источники P2.5/P2.2 Waveshare и приблизительные концы возле серво сохранены.

В седле, на участке Y80…86 мм, центры проводов находятся при X44 мм и Z39,15/40,95 мм. Резерв диаметра каждого — 1,6 мм, расстояние между центрами — 1,8 мм. Новые длины осей: VOUT **136,330 мм**, GND **143,037 мм**; это не размеры для резки.

Фиолетовая петля — резерв шнура Ø0,8 мм, кубик — место под узел 3×3×2 мм. Петля проходит через существующее отверстие 1,3×2,8 мм, охватывает крыло снизу и закрывает выход из открытого седла сверху. Форма настоящего узла, концы шнура, материал и натяжение ещё не заданы. Это предложение удержания пары в направляющей, **не доказанная разгрузка пайки от осевого рывка**.

Проверки при электронике 0 / камере +3 мм:

- Новые маршруты не пересекают учтённые детали, друг друга или сигнал D3. Петля и место под узел также проходят проверку; за условную полость кузова ничего нового не выходит.
- Если заполнить существующее отверстие прижима, оно пересекает петлю на 0,777 мм³. Проход действительно используется.
- При локальном подъёме верхнего провода на 1 мм возникает пересечение со шнуром 0,244 мм³. В этом же положении открытый прижим без шнура провод не задерживает. Это проверка одного направления перемещения жёстких объёмов, а не усилия удержания или всех способов выхода гибкого провода.
- Обслуживание проходит с 172 неподвижными объектами: 265 положений кузова, 25 положений левого упора, непрерывный выход коробки батареи на 50 мм влево. Для обслуживания учтён полный Waveshare без контактных окон.

Условия замены батареи прежние: питание выключено, USB и батарея отсоединены, кузов, лента и левый упор сняты. Для **снятия самого прижима** сначала освободить вязку и отвести провода; извлечение прижима с новым жгутом здесь не моделировалось. Старые проверки снятия прижима не переносятся на эту проводку.

Радиусы изгиба, натяжение, скольжение, воздействие на изоляцию, доступ пальцев, прочность при ударе и реальная посадка пока не проверены. На длинной паре есть только эта одна предложенная точка удержания; фиксация возле выводов Waveshare и серво ещё открыта. Электрические ограничения, реальный кабель/разъём, RF и незавершённый силовой вход сохраняются из [предыдущей сборки](../servo-power/README.md). Конфликт клеммы мотора A также остаётся. Печать и монтаж не выполнялись.

## Воспроизведение

После подготовки предыдущей сборки:

```powershell
uv run --with-requirements tools/cad-candidate-requirements.txt python tools/build_servo_lacing.py
uv run --with-requirements tools/cad-candidate-requirements.txt python tools/build_servo_lacing_view.py
```

`--fit-only` выполняет только проверку начальной посадки, без итогового отчёта обслуживания. STL в этой папке — провода, шнур и резерв узла, не печатные детали. Все исходные печатные детали сохранены побайтно. SHA256 записаны в отчётах; [браузерная проверка](browser-check.json) подтверждает 78 уникальных объектов, видимую вязку и WebGL error 0. Крупный вид просмотрен. Модели и лицензии наследуются из [NOTICE](../packaging-v05/NOTICE.md).
