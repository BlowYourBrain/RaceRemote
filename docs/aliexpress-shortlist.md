## Пока только сравнить, не считать готовой покупкой

- **USB-C 2S LiPo charger 8.4V**, в том числе платы **IP2326**: нужны размер, схема/маркировка, настраиваемый ток для нашей 600 мА·ч батареи, завершение заряда и данные о балансировке/защите. Наличие USB-C или слова «2S» недостаточно. Конкретный зарядный модуль пока не выбран.
- **2S protection/balancing board**: подбор зависит от схемы зарядки и измеренных токов. BMS не заменяет зарядник. Не заказывать случайный модуль на 20/30 А только по надписи.
- USB-C breakout для общего порта: нужны линии **D+/D−**, цепи **CC**, размеры и схема. Переходник micro-USB → USB-C из прежней ссылки пользователя не является зарядником.
- Разъёмы **JST-RCY 2 pin** и **JST-XH 3 pin 2.54 mm** — визуальные кандидаты к батарее, физическое совпадение и распиновка пока не измерены. Магниты кузова — размер/количество после CAD креплений.

## Найденная пользователем карточка XIAO C5

[AliExpress 1005006935181127, SKU 12000038778857281](https://aliexpress.ru/item/1005006935181127.html?sku_id=12000038778857281) прислана пользователем с описанием «XIAO ESP32C5». Сам выбранный SKU не проверен; карточка может объединять варианты. Если выбрана C5, это **не наш текущий кандидат S3 Sense**. [Документация C5](https://wiki.seeedstudio.com/xiao_esp32c5_getting_started/) и [S3 Sense](https://wiki.seeedstudio.com/xiao_esp32s3_getting_started/) описывают разные платы; подготовленная прошивка камеры ориентирована на S3 Sense. Наличие S3 на общей фотографии не подтверждает состав выбранного варианта.

Для найденной альтернативы нужны ссылка, название выбранного варианта, комплектация, цена с доставкой и чертёж/габариты. До проверки одного образца не считать комплект утверждённым для всех 4–6 машин.

Пользователь затем прислал [AliExpress 1005008098777836, SKU 12000047074308686](https://aliexpress.ru/item/1005008098777836.html?sku_id=12000047074308686) и уточнил: **S3 с антенной, без камеры**. Комплектация записана со слов пользователя, выбранный SKU инструментом не прочитан. Внешний поиск показывает общее название карточки с Sense/OV2640, но оно не заменяет выбранный вариант и не доказывает наличие камеры.

Ориентир сенсора остаётся **OV3660**. Для дополнения базовой S3 искать `XIAO ESP32S3 Sense expansion board OV3660`: нужны совместимая плата расширения Sense и камера, а не произвольный сенсор OV3660 на шлейфе. Конкретный комплект ещё не выбран; пользователь не нашёл полный вариант с нужной камерой. Цена и доставка присланного SKU не установлены.
