# Контракты RaceRemote

Обновлено: 14 сентября 2026 года. Редакция документа: 0.34. Для первого стенда реализован [Control v1](control-v1.md); AP и STA используют одинаковые пакеты и тайм-ауты. Для видео реализован [Android MJPEG-приёмник 0.1](video-v0.md), пока без проверки реальной камеры.

По просьбе пользователя ключевые моменты и контракты фиксируются по мере работы. Этот файл описывает договорённости между частями системы; точные параметры добавляются после выбора компонентов и проверки. Наличие строки в реестре не означает, что интерфейс реализован.

## Как записывать новый или изменённый контракт

Указать ID, статус (предложен / принят / реализован / проверен / заменён), дату и причину решения, участников, формат или геометрию, единицы и допустимые значения, поведение при ошибках, совместимость версий и способ проверки. Для выполненных проверок сохранять конкретную ревизию и результат. При замене оставлять краткую запись, что именно изменилось.
