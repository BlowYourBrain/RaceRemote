# Symbol provenance

`PI3USB9201ZTA` is an original project symbol drawn from Diodes Incorporated
DS41358 Rev3-2, April 2025, p2. Numeric package pins 1–12 follow the top-view
pinout. No footprint or electrical simulation model is assigned.

`R`, `C`, `Conn_01x02`, `Conn_01x04`, and `PWR_FLAG` are unchanged subsets
of the official KiCad 10.0.6 Windows distribution, reused from
[`hardware/charge-core`](../charge-core/NOTICE.md).
